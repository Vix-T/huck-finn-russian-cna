# Betweenness centrality

Generated by `uv run --frozen python -m huckfinn_cna.centrality` from the frozen networks (networks-v1).
Tables only. Betweenness is exact (no sampling) and normalized as networkx does. Ranks: 1 = highest; ties share the best rank.

Variants: **undirected** = Undirected, unweighted; **directed** = Directed, unweighted; **weighted** = Directed, distance 1/count (old method); **adjusted** = Frequency-adjusted (undirected).
Frequency adjustment: 30 shuffles per text (word tokens permuted across the text, sentence lengths kept, network rebuilt with the same rules); adjusted = real / mean shuffled undirected betweenness; z = (real − mean) / SD (ddof 1). Seed: numpy `default_rng([20261027, text index])`.
